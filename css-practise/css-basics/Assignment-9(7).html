Responsive Design

Responsive web design makes a website adapt to different screen sizes such as desktops, tablets and mobile phones.

CSS Grid, Flexbox, relative units and media queries are commonly used to create responsive websites.

CSS Cheat Sheet

Flexbox

Used for one-dimensional layouts.

Grid

Used for two-dimensional layouts.

Media Query

Changes styles according to screen size.
