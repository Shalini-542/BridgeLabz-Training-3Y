Responsive Design Principles

Fluid Layouts

Fluid layouts use flexible units such as percentages to adjust according to screen size. 

width: 100%;
max-width: 1200px;

Flexible Media

Images and videos should resize automatically so they fit inside their containers. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Media queries allow different styles for different screen sizes. 

@media (max-width: 600px) {
    body {
        font-size: 14px;
    }
}
